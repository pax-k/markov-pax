# Security Policy

## Supported version

Security fixes apply to the latest released version. Version 0.1.0 is not published yet.

## Report a vulnerability

Use the repository host's private vulnerability-reporting feature. Do not put sensitive details, credentials, personal data, or an unpatched exploit in a public issue.

Include:

- The affected version or revision.
- The affected API and input.
- The observed effect.
- The smallest safe reproduction.
- A suggested fix, if known.

The maintainer will confirm receipt, assess impact, prepare a fix, and coordinate disclosure. This file does not promise a response time.

## Scope

The package performs local mathematical computation. A model result is not a security control, clinical decision, safety certification, or production validation. Applications must validate untrusted data and enforce their own authorization and resource limits.
